# brown reader

![brown reader](icon128.png)

在网页中选择纯文本 `span` 或 `div`，用小说内容替换其文字的浏览器插件。可同时选中多处拼成一页，阅读时沿用网页原有的字体和颜色。

## 安装

1. 下载并解压代码。
2. 打开浏览器扩展管理页面，开启开发者模式。
3. 点击「加载已解压的扩展程序」，选择代码文件夹。
4. 更新插件后，在扩展管理页面点击「重新加载」，并刷新正在阅读的网页。

## 使用

1. 在普通 HTTP/HTTPS 网页打开插件，导入 TXT 或 EPUB 小说。TXT 支持 UTF-8 和 GBK；EPUB 解析期间请保持弹窗打开。
2. 选择小说，可按阅读进度百分比跳转。选择网页区域后，按其原始空间和字体自动分页。
   也可通过「章节目录」直接跳转，跳转后继续按所选区域分页。
3. 点击「选择网页元素」，弹窗关闭后，将鼠标移到网页中的纯文本 `span/div` 上。
4. 出现蓝色轮廓后点击，该区域被标为绿色。可继续点选多处拼成更大的一页，再次点击绿色区域可取消。
5. 按回车开始阅读，小说会替换这些位置的原文字。按 `Esc` 可取消选择。
6. 按 `A` 上一页、`D` 下一页，阅读进度自动保存。
7. 按 `S` 或 `F1` 切换原文字与小说。
8. 切换到其他应用或标签页时自动还原原文字，返回后需再次按 `S` 或 `F1` 显示。
9. 刷新或重新打开同一页面后自动重新绑定这些区域，按 `S` 或 `F1` 继续阅读。

## 限制

- 支持 TXT 和无 DRM 的文字 EPUB 2/3，不支持 PDF、MOBI 或 Word。
- EPUB 按书内阅读顺序提取 XHTML 正文和段落分隔，读取 EPUB 3 nav 或 EPUB 2 NCX 目录，保留目录层级及章节锚点；不显示图片、原书样式及附属非线性章节，不执行书内脚本。
- TXT 根据独立短行识别「第一章」「第十二回」「Chapter 2」及序章、后记等标题，非标准标题可能无法识别。
- 没有可用目录时仍可翻页或按百分比跳转；EPUB 目录中不在已提取正文内的目标或失效锚点不展示。此前导入的书籍需要重新导入才能生成章节目录，重新导入会创建独立记录。
- EPUB 文件最多 50 MB；单个解压文档最多 8 MB，累计读取文档最多 40 MB。正文加密、章节缺失或损坏会提示导入失败。
- EPUB 与 TXT 一样，每条导入记录独立保存正文位置，旧页码会自动换算为正文位置。重复导入会创建新的记录。
- 仅允许选择可见、无子元素、有文字的 `span/div`，链接、按钮和可编辑区域不可选择。
- 输入框内打字不会触发阅读快捷键。
- 阅读快捷键由插件独占，不会同时触发网页自身的同名快捷键。
- 阅读区域按「协议 + 域名 + 路径」记忆，刷新或重新打开同一页面时自动重新绑定，需按 `S` 或 `F1` 显示；网页结构变化导致任一区域找不到时需重新选择。
- 网页自身重新渲染文字时可能覆盖小说内容，请选择相对静态的区域。
- 浏览器内部页面、扩展商店等受限制页面不可使用。
- 小说沿用目标元素的布局；每页只显示实际放得下的文字，下一页从其末尾继续。多选时按选择顺序依次填充，每个元素都不会超出自身原有尺寸，因此网页布局保持不变。区域尺寸或字体变化时重新排版，保留当前位置。
- 所有区域都连一个完整字符都放不下时会恢复原文字并提示，请扩大区域或重新选择。

## 隐私

小说和阅读进度保存在本地，不上传服务器。

## 开发验证

使用 Node.js 22+ 和本机 Chromium 运行章节测试：

```sh
node tests/run-chapters.mjs /path/to/chromium
```

测试覆盖 TXT 标题识别、EPUB 2/3 目录及锚点、IndexedDB 存储和弹窗章节跳转；扩展通信和标签页接口使用测试实现。
